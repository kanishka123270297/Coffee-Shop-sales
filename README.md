# Coffee Shop Sales Dashboard

## Project Overview
This project analyzes coffee shop sales data using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard

## Key Analysis
- Total Sales
- Total Orders
- Total Quantity Sold
- Sales by Product
- Sales by Month
- Sales by Day
- Sales by Store Location

## Project Objective
The objective of this project is to analyze coffee shop sales data and identify sales trends, popular products, and overall business performance.
